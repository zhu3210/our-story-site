# 我们的故事：私密恋爱纪念网站

一个要密码才能进的网站，有三个页面：

- **地图**：可以缩放的地球，标出你们去过的每个地方，按时间顺序用弧线连起来。点地点会看到当时的经历和照片。
- **相册**：按地点和年份整理的照片。点开大图可以一键跳回地图上的那个地方。
- **视频**：每年一个恋爱视频。

全部用免费服务：网站放在 Cloudflare Workers 上，地图底图来自 OpenFreeMap，不需要绑定信用卡。

## 准备（第一次用）

1. 安装 [Node.js](https://nodejs.org/)（18 以上）和 [uv](https://docs.astral.sh/uv/)（用来运行整理照片的 Python 脚本）。
2. 在项目文件夹里安装依赖：

```powershell
npm.cmd install
```

3. 把 `content.example` 文件夹复制一份，改名为 `content`，然后打开 `content/site.yaml` 改成你们自己的标题、名字和在一起的日期。`content/` 不会进 Git，你们的照片和信息只留在自己电脑上。
4. 本机预览用的密码：在项目根目录新建一个 `.dev.vars` 文件，写一行 `SITE_PASSWORD=随便设一个本机密码`（这个文件也不会进 Git）。

> Mac / Linux 上把下面命令里的 `npm.cmd`、`npx.cmd` 换成 `npm`、`npx`。

## 工作原理

```
content/（你的原件，只留在本机）
   │  npm.cmd run build：压缩照片、读取拍摄时间和 GPS、把视频切成小段
   ▼
public/（网站文件）
   │  npm.cmd run deploy：上传到 Cloudflare
   ▼
https://our-story.<你的子域名>.workers.dev
   ▲
   └─ src/worker.js：每个请求先检查密码，没登录的人拿不到任何照片和视频
```

## 在网站上直接上传（最简单）

登录网站后，点右上角的 **＋ 上传**：

1. 选择照片，可以一次选很多张，也可以直接拖进来。手机上会直接打开相册。
2. 地点只精确到城市：中国的照片按地级市归类（比如朝阳区、海淀区都算「北京」），国外按城镇归类（比如巴塞罗那、牛津）。网站会根据每张照片的 GPS 自动分到对应的城市：已经有的城市就放进去，没有就新建（地点名字默认用城市名，标在城市中心）。一次选的照片可以来自好几个城市。没有定位的照片需要手动选一个地点。
   如果把某个地点改成一个已经存在的城市，网站会问要不要把两个合并成一个。
   地名识别用的是 OpenStreetMap 的免费服务 Nominatim（[使用条款](https://operations.osmfoundation.org/policies/nominatim/)：每秒最多 1 次、不能批量查询）。只会发送取整到约 100 米的坐标，不会发送照片。网站每次上传或点地图只查一次，并会缓存结果。
3. 点「开始上传」。照片会先在浏览器里压缩（大图最长边 2000 像素，约 0.4 MB），再上传。

其他操作：

- **编辑地点**：在地图上点开一个地点，点「编辑」，可以修改名字、日期、经历和位置。在网站上新建的地点还可以整个删除。
- **处理照片**：在相册里**右键点照片**（手机上长按），可以查看大图、在地图上看、设为封面、编辑说明和拍摄日期、**移到其他地点**、下载、删除。打开大图后，下面也有同样的按钮。
- **一次处理多张**：按住 Ctrl（Mac 上是 Cmd）点照片可以多选，按住 Shift 可以连续选一段，选好后用底部的工具条「移到其他地点」或「删除」。
- **移到其他地点**有三种方式：放进已有的地点、新建一个地点，或者按每张照片的定位自动分到对应的城市（适合整理之前放错的照片）。照片删掉或移走后，原来的地点如果一张照片都不剩，会自动删除；只有写过经历文字的地点会先问一下，免得文字被悄悄删掉。上传中途失败留下的空地点，10 分钟后也会自动清理。
- 编辑、移动、删除只对在网站上传的照片有效；电脑上 content 文件夹里的照片要在电脑上改。

相册右上角会显示已经用了多少空间、大约还能放多少张。网站上传的照片存在 Cloudflare KV（免费 1 GB，约 2500 张），地点和文字存在 Cloudflare D1（免费）。免费版每天最多写入 1000 次，每张照片要写 2 次，所以每天最多能传大约 500 张。超出后当天会提示上传失败，第二天（UTC 0 点）恢复，不会扣钱。照片特别多时，建议用下面「在电脑上添加」的方式批量放。

两种方式可以混用：网站上传的照片可以放进电脑上建的地点，反过来也一样。

**备份网站上传的内容**：网站上传的照片只存在 Cloudflare 上，电脑上没有。想备份时可以让 Claude 帮你导出。

## 照片的拍摄地点

地点只精确到城市，但每张照片自己的 GPS 位置也会显示：

- 地球视角只看到城市标记；**放大到城市附近**，每张照片会出现在它的拍摄地点，靠得很近的几张合成一个带数字的小圆，点一下会放大分开（拍在同一个位置的会直接打开）。点照片看大图。
- 城市标记和连线：照片有两张以上的地点，标在城市（行政区）中心，连线也连到中心；**只有一张照片的地点，直接标在这张照片的位置**。
- 在列表或时光轴里选一个城市，地图会把这个城市所有照片的拍摄地点框进画面。
- 照片的「在地图上看」会飞到这张照片拍摄的那个点。

## 想去的地方

地图右侧面板顶部可以在「去过 / 想去」之间切换。在「想去」里点「＋ 想去的地方」，搜索地名（比如「京都」「冰岛」），或者直接在小地图上点一下，城市和国家会自动识别，还可以写上想在那里一起做什么。

- 想去的地方在地图上是一个虚线的 ♡ 小标记，不会连进旅行路线。
- 去过之后，上传在那个城市拍的照片，它会自动变成「去过的地方」，网页上会提示一声。在它的面板里点「去过了！上传照片」也一样。
- 如果把它的照片全部删掉，它会变回「想去的地方」，不会被自动删除。

## 地图下面的小时光轴

地图页底部有一条可以左右滑的时光轴，按时间排着：在一起的那天、每一次旅行（同一个城市隔了几天以上再去，算新的一次）、纪念日（在一起第 100、200、300、520、1000、1314 天和每个周年）、今天，最后是想去的地方。点旅行会飞到那个城市；鼠标停在「今天」上能看到下一个纪念日还有几天。

## 地图风格

地图左上角可以在 **水彩** 和 **复古** 两种风格之间切换，每台设备会记住自己上次选的风格。默认是水彩。

- **水彩**：Stamen Watercolor 水彩底图（[史密森尼库珀·休伊特设计博物馆](https://watercolormaps.collection.cooperhewitt.org/)永久保存的版本，免费使用，须署名 Stamen Design，CC BY 3.0）。这个底图站不允许其他网站直接加载，所以瓦片由我们的 Worker 转发（`/tiles/watercolor/...`），同样要登录才能访问。底图最多放大到 13 级，大约是城区范围。
- **复古**：在 OpenFreeMap 的地图上重新配色，米黄旧纸、灰青海洋、砖红道路、深褐色虚线国界，再叠一层很淡的纸张纹理。

想改默认风格，可以在 `content/site.yaml` 里加一行 `map_theme: vintage`（或 `watercolor`）。

## 一、在电脑上添加一个地方（适合大批量）

1. 在 `content/places/` 里新建一个文件夹，名字以日期开头，例如 `2025-10-巴黎`。
2. 把这次的照片放进去，支持 JPG、HEIC（iPhone 照片）、PNG 和 WEBP。
3. 在同一个文件夹里新建 `place.md`，格式如下：

```markdown
---
title: 塞纳河边散步          # 显示的标题
city: 巴黎
country: 法国                # 用来统计去过几个国家
lat: 48.8566                 # 纬度（可省略：照片自带 GPS 时会自动定位）
lng: 2.3522                  # 经度
date: 2025-10-01             # 开始日期（可省略：自动取最早一张照片的拍摄日期）
end_date: 2025-10-05         # 结束日期（可省略）
cover: IMG_1234.jpg          # 地图上显示的封面照片（可省略：默认用第一张）
zoom: 11                     # 地图放大到多大（可省略，默认 10，数字越大越近）
captions:                    # 给某几张照片写一句话（可省略）
  IMG_1234.jpg: 第一次一起看铁塔亮灯
---
在这里写你们在这个地方的经历。

空一行就是新的一段。
```

不知道经纬度时，在 Google 地图上右键点那个地方就能复制，也可以直接让 Claude 帮你填。

4. 生成网站文件，再在本机预览：

```powershell
npm.cmd run build
npm.cmd run dev
```

用浏览器打开 http://localhost:8787 ，本机预览用的密码写在 `.dev.vars` 里。

5. 确认没问题后上线：`npm.cmd run deploy`

## 在网站上上传视频

在「视频」页点右上角的 **＋ 上传视频**，选一个视频，填好年份、标题和说明就行。年份会根据视频的拍摄时间自动填上。

- 视频会先在你的浏览器里压缩成 720p（大约每分钟 15 MB），再分成 5 MB 一段上传，所以原视频再大也没关系。压缩一般比视频本身的时长更快，上传过程中不要关闭页面。
- 建议用电脑上的 Chrome 或 Edge 上传。有些浏览器不支持压缩，这时如果原文件不超过 300 MB、浏览器也能直接播放，会问你要不要直接上传原文件。
- 视频和照片共用 1 GB 的免费空间：一个 5 分钟的视频大约占 75 MB。相册右上角能看到还剩多少空间。
- 在视频卡片上可以修改年份、标题、说明，也可以删除。

## 二、在电脑上添加每年的视频

把视频放进 `content/videos/`，文件名以年份开头，例如 `2025-我们的第五年.mp4`。

如果想写标题和说明，就再建一个同名的 `.md` 文件，例如 `2025-我们的第五年.md`：

```markdown
---
title: 我们的第五年
---
这一年我们一起去了……
```

运行 `npm.cmd run build` 时，视频会被自动转成 720p，并切成 6 秒一段的小文件（HLS 格式）。这样做是因为 Cloudflare 免费版的单个文件不能超过 25 MB。一个 10 分钟的视频大约需要转码几分钟，转过一次就不会重复转。

## 三、第一次上线（只需要做一次）

1. 注册一个免费的 Cloudflare 账号：https://dash.cloudflare.com/sign-up
2. 在本项目文件夹里打开终端，登录 Cloudflare。浏览器会弹出授权页面，点允许即可：

```powershell
npx.cmd wrangler login
```

3. 创建存照片的 KV 和存地点信息的 D1 数据库（都是免费的，不用绑卡）。命令会自动把它们写进 `wrangler.jsonc`：

```powershell
npx.cmd wrangler kv namespace create photos --binding PHOTOS --update-config
npx.cmd wrangler d1 create our-story-db --binding DB --update-config
```

4. 设置网站密码。运行后按提示输入密码，密码会加密保存在 Cloudflare，不会写进任何文件：

```powershell
npx.cmd wrangler secret put SITE_PASSWORD
```

5. 生成网站文件并上传：

```powershell
npm.cmd run deploy
```

第一次部署时，Cloudflare 会让你给自己选一个 `workers.dev` 子域名。部署完成后，终端里会显示网址，把它和密码发给另一半就行。

**改密码**：再运行一次第 4 步。改完后，所有已登录的设备都会自动退出。

**想要好记的网址**（可选，要花钱）：买一个自己的域名（每年大约 10 欧元），然后在 Cloudflare 后台把它绑定到这个 Worker。

## 改网站标题、名字、在一起的日期

都在 `content/site.yaml` 里，改完运行 `npm.cmd run deploy`。登录页上的标题在 `wrangler.jsonc` 的 `SITE_TITLE`（登录页没密码也能看到，建议不要写真实姓名）。

## 免费额度够不够用

| 项目 | 免费上限 | 说明 |
|---|---|---|
| 访问次数 | 每天 10 万次 | 每张照片、每段视频都算一次。两个人日常看完全用不完。超出后当天会显示 429 错误，第二天（UTC 0 点）自动恢复，**不会扣钱**。 |
| 单个文件 | 25 MB | 照片压缩后约 0.3–1 MB，视频每段约 2 MB。 |
| 文件总数 | 20000 个 | 每张照片占 2 个文件（大图和缩略图），大约能放 9000 张。`build` 结束时会显示当前的文件数。 |
| 地图 | 不限 | OpenFreeMap 免费，不用注册。 |

## 隐私说明

- 上传到 Cloudflare 的只是压缩后的照片和视频，原件一直留在你电脑上的 `content/` 里。**请自己另外备份 `content/`**，它不在任何云端。
- 照片上网前会去掉 EXIF 信息，包括 GPS 位置和相机型号。
- 密码是在服务器端检查的：没有密码的人，就算知道照片的网址也拿不到。
- 网站设置了不让搜索引擎收录。
- 地图底图是从 OpenFreeMap 下载的。浏览器只会按你正在看的区域请求地图图块，不会把照片或文字发给它。

## 文件说明

| 路径 | 作用 |
|---|---|
| `content/` | 你的原件：照片、视频、文字（不会上传，也不进 Git） |
| `content.example/` | `content/` 的示例，第一次用时复制一份 |
| `tools/build.py` | 把 content 整理成网站文件 |
| `public/` | 网站本身；其中 `media/` 和 `data/` 是自动生成的，不用手动改 |
| `src/worker.js` | 密码门 |
| `wrangler.jsonc` | Cloudflare 配置，`SITE_TITLE` 是登录页显示的标题 |
| `.dev.vars` | 本机预览用的密码 |
